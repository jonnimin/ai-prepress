# AI 印前助手

![AI 印前助手封面](doc/ai-prepress-cover.png)

AI 印前助手是一個面向印刷前處理流程的 Web 工具原型，協助使用者在送印前完成檔案檢查、PDF 轉換、出血與裁切線處理、CMYK 轉換、文字外框化與印刷就緒檢查等工作。專案目標是把常見的印前檢查步驟整理成簡潔的線上流程，降低設計稿進入印刷生產前的溝通成本與返工風險。

## 專案特色

- 印前檔案檢查：檢查上傳檔案是否符合基本印刷需求。
- PDF 與印刷格式處理：提供 PDF 轉換、CMYK 轉換與文字外框化流程。
- 出血與裁切輔助：支援出血、裁切線與印刷標記相關處理。
- 印刷方案頁面：包含合作、方案、付款示範、作品集與印刷估價等前台頁面。
- API 模組化：後端功能依印前任務拆分，方便後續擴充處理流程。

## 目錄結構

```text
.
├── api/                 # 印前處理 API 與共用邏輯
├── doc/                 # 專案文件圖片與說明素材
├── icc/                 # 色彩描述檔相關說明
├── skin/                # 前端樣式、圖片與 JavaScript
├── uploads/             # 使用者上傳暫存目錄，不納入 Git
├── outputs/             # 處理輸出暫存目錄，不納入 Git
├── index.html           # 主頁
├── print-pricing.html   # 印刷估價頁
├── plans.html           # 方案頁
├── payment-demo.html    # 付款示範頁
├── cooperation.html     # 合作頁
└── testpdf.php          # PDF 測試入口
```

## 基本使用

將專案部署到支援 PHP 的 Web Server 後，開啟 `index.html` 即可進入前台介面。後端 API 位於 `api/` 目錄，檔案上傳與處理輸出預設分別使用 `uploads/` 與 `outputs/` 目錄。

部署前請確認伺服器具備專案所需的 PHP 執行環境，以及實際印前處理流程需要的外部工具或函式庫。
